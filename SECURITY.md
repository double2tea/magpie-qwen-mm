# Security

This plugin connects local tools to your Magpie gateway. Configure provider credentials in Magpie, not in issues, screenshots or source files. The local settings service binds to loopback and requires a private page credential for API operations. Magpie Web access uses Magpie's authentication.

Native provider relay has different accounting and model-budget limitations from Magpie's standard routed APIs. Read the README before enabling native speech calls. Reverse-image search retains its original provider and may upload an image according to the upstream tool's behavior.

Do not attach `.config/magpie` files, `.qwen-mm-plugins/config`, `page-token`, cookies, authentication headers, private media, or configuration backups to bug reports.

For a potential vulnerability, use GitHub's private vulnerability reporting feature on this repository when available. If unavailable, open an issue requesting a private contact channel without exploit details or secrets. Never publish credentials to demonstrate a problem.

This is a small community integration. There is no guaranteed response time or security support SLA. Keep your existing configuration backups private.
